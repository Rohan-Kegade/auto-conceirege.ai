# frontend

## Tech stack

- **Vite** — build tool / dev server
- **React** + **TypeScript**
- **Tailwind CSS v4**
- **React Router**

## Run locally

Requires Node 18+.

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production bundle
npm run lint     # tsc -b --noEmit
```
